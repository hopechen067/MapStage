# 参数列表说明 · Map preset

Field names match tuner export and [`tuner/preset-antique-default.json`](../tuner/preset-antique-default.json).  
Defaults below = **antique parchment v3** (current homepage).

Legacy JSON with `maplibre` instead of `mapstage` still merges. Prefer `mapstage`.

## Root

| Field | Type | Default | Notes |
|------|------|---------|-------|
| `id` | string | `antique-default` | Preset id |
| `label` | string | `Antique parchment default` | Human label |
| `version` | number | `3` | Schema version. Tuner export is always `3`. |
| `savedAt` | string | ISO-like datetime | Export timestamp |
| `season` | string \| null | `null` | Optional `spring` / `summer` / `autumn` / `winter` |

## `camera`

| Field | Type | Default | Notes |
|------|------|---------|-------|
| `center` | `[lng, lat]` | `[104.0, 35.5]` | Default China overview |
| `zoom` | number | `4.2` | Overview scale |
| `pitch` | number | `28` | Degrees |
| `bearing` | number | `0` | Degrees |

## `mapstage`

| Field | Type | Default | Notes |
|------|------|---------|-------|
| `backgroundColor` | color | `#c8c2b4` | Map background / parchment base |
| `terrainExaggeration` | number | `1` | `map.setTerrain({ exaggeration })`. `1` = real elevation. |

### `mapstage.water`

Still present in JSON for old overlay paint. The **public tuner does not drive OpenFreeMap water from these keys**. Export keeps them; `ui.showWater` is forced `false`.

| Field | Type | Default |
|------|------|---------|
| `lakeFill` | color | `rgba(50,118,138,0.9)` |
| `lakeOutline` | color | `rgba(90,110,105,0.8)` |
| `riverLevel3` | color | `rgba(48,112,128,0.55)` |
| `riverLevel2` | color | `rgba(45,110,125,0.88)` |
| `riverLevel1` | color | `rgba(42,105,120,0.95)` |
| `highlightRiver` | color | `rgba(38,100,118,1)` |
| `riverL3Width` | number | `1.2` |
| `riverL2Width` | number | `2` |
| `riverL1Width` | number | `1.8` |
| `highlightWidth` | number | `2.4` |

**Alias (legacy JSON only):** `qilianRiver` → `highlightRiver`, `qilianWidth` → `highlightWidth`.

## `css`

Applied as CSS `filter` + warm-tint overlay + vignette on the map canvas wrapper. Gated by `ui.showCssFilter`.

| Field | Type | Default | Notes |
|------|------|---------|-------|
| `sepia` | number | `0.08` | |
| `saturate` | number | `0.98` | |
| `contrast` | number | `1.03` | |
| `brightness` | number | `1.0` | |
| `hueRotate` | number | `-1` | Degrees |
| `warmTintAlpha` | number | `0.04` | Soft-light overlay alpha |
| `warmTintColor` | color | `#9a8868` | Warm tint |
| `vignetteStrength` | number | `0.1` | Edge darken |

## `ui`

| Field | Type | Default | Notes |
|------|------|---------|-------|
| `projection` | `map` \| `globe` | `map` | Map = mercator; globe = globe projection |
| `showSatellite` | boolean | `true` | EOX raster (when tiles are configured) |
| `showRelief` | boolean | `false` | Hypsometric `color-relief` on Mapterhorn |
| `showCssFilter` | boolean | `true` | Antique CSS stack |
| `showCities` | boolean | `true` | Settlement extrusions / labels |
| `showRef` | boolean | `false` | Reference image compare (tuner only) |
| `showWater` | boolean | `false` | Old GeoJSON overlay. Public export always `false`. |
| `showHighlight` | boolean | `false` | Overlay highlight rivers. Public export always `false`. |

Optional tuner-only: `showRiverLabels`, `refMode` (`pip` \| `split`).

**Alias (legacy):** `showQilian` → `showHighlight`.

## `isolate`

| Field | Type | Default | Notes |
|------|------|---------|-------|
| `enabled` | boolean | `false` | Terrain island / parchment mask |
| `regionId` | string | `china` | Catalog id from `REGION_ISOLATE_DATA` (default silhouette is narrative, not an official border) |

## `cities`

| Field | Type | Default | Notes |
|------|------|---------|-------|
| `dataFile` | string | `assets/sample-sites.json` | Relative to tuner root |
| `halfKm` | number | `18` | Global half-edge km fallback |
| `renderMode` | string | `fill-extrusion` | Extrusion mode |

See [`city-tier-schema.md`](city-tier-schema.md) for per-tier `halfKm` defaults.
