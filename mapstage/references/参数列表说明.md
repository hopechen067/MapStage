# 参数列表说明 · Map preset

Field names match `tuner/preset-antique-default.json` (version 2).  
Defaults below = **antique parchment v2**.

## Root

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `id` | string | `antique-default` | Preset id |
| `label` | string | `Antique parchment default` | Human label |
| `version` | number | `2` | Schema version |
| `savedAt` | string | ISO-like datetime | Export timestamp |

## `camera`

| Field | Type | Default | Notes |
|-------|------|---------|-------|

| `zoom` | number | `4.2` | Overview scale |

| `bearing` | number | `0` | Degrees |

## `ui`

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `showWater` | boolean | `true` | All water layers |
| `showRoads` | boolean | `true` | Road overlay (Studio only; the story runtime never draws roads) |
| `skinId` | string | `parchment` | Vector skin, see [skins](look.md#skins) |
| `basemapId` | string \| null | — | Basemap style last applied in Studio: `satellite` / `natural` / `atlas` / `paper` / `ink` / `qinglv` / `nightlights` / `dusk` (see [底图样式](look.md#basemap)). Cleared to `null` when you edit the elevation ramp by hand. `MapStage.mount` draws it unless `story.look.basemap` says otherwise; `satellite` is ignored there |
| `showCities` | boolean | `true` | Settlement extrusions / labels |
| `showRef` | boolean | `false` | Reference image compare (tuner only) |
| `showRegionIsolate` | boolean | `false` | Hide outside selected polygon with parchment |
| `regionIsolateId` | string | `china` | Catalog id, or `custom` after paste |

Optional tuner-only: `refMode` (`pip` \| `split`). Retired and dropped on load: `showHighlight`, `showQilian`, `showRiverLabels`.

## `vector`

Studio vector colouring (relief, layer colours, night lights). A basemap style button writes all of these at once (`AntiqueTunerVector.applyBasemapParams`); `MapStage.mount` reads them back, see [Story 规范 · look](story-spec.md#look).

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `relief` | boolean | `false` | Elevation tint (`color-relief` on the Terrarium DEM; negative heights tint the sea) |
| `reliefOpacity` | number | `1` | 0–1 |
| `elevStops` | array \| null | `null` | `[{ h, color, label }]` ascending by metres; `null` = default ramp |
| `contour` | boolean | `false` | Contour lines (Studio only) |
| `landcover` | boolean | `false` | Forest / grass / farmland / urban fills |
| `lights` | boolean | `false` | Vector night lights: place-point glow, urban landuse, glowing trunk roads |
| `nightRaster` | boolean | `false` | Night-lights image. **Simulated from GeoNames settlements, not satellite data** — see [夜景与夜光图](look.md#night-lights). Source comes from `nightLights` in `map-tiles.config.js` |
| `paint` | object \| null | `null` | Custom layer colours; `null` = the skin's colours |

## `cities`

See [`city-tier-schema.md`](city-tier-schema.md) for per-tier `halfKm` defaults.
