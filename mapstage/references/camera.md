# 镜头 Camera

镜头规则几乎全部来自长征系列的返工记录。核心一句话：**机位跟着口播走，一句一动，动完停稳。**

## 一句一动 {#one-move}

- 一句口播最多一次**有目的**的移动，到位后停稳。长征 ep02 去掉无目的偏航后，全集机位从 59 个降到 38 个，观感反而更稳。
- 默认移动时长 2.2 s，`smoothstep` 缓入缓出。
- 停稳段只做两件事：缓推约 6–7%（`push`，zoom +0.09 ≈ 视距缩 6%）和俯仰 +3°（`tilt`）。
- 不做无意义的漂移、旋转、呼吸。

## 自动取景 {#fit}

机位不是手写的，是从「当句讲到哪几个地点」反算出来的（cz_render `camfit.py`）：

1. 取当句主体的地点集合（`shots[].fit`）。
2. 投影到 16:9 **安全区** `[0.06, 0.22, 0.94, 0.78]`（归一化屏幕坐标 x0, y0, x1, y1）——上下留给字幕和字卡。
3. 按目标俯仰 / 朝向把点透视投影到屏幕，迭代求能放下这些点的 zoom 与中心，点群在安全区里居中。
4. 默认俯角 40°。

```js
const pad = MapStage.safePadding(width, height);              // 安全区 → 像素 padding
const cam = MapStage.fitCamera(points, { width, height, padding: pad, pitch: 40, bearing: 0, maxZoom: 9 });
map.jumpTo(cam);                                               // { center, zoom, pitch, bearing }
```

`fitCamera` 计入俯仰和朝向（`shots[].fit` 与 `board.fit()` 都走它）。不要用 `map.cameraForBounds` / `map.fitBounds`：MapLibre 5.6 下它们按平面算，俯角 40° 时近处（画面下方）的点会被裁出画面。`fitCamera` 是纯数学（海平面 Web Mercator，复刻 MapLibre 的透视），不读地形、不等瓦片，同输入同机位；有地形时屏幕位置会差 1–2 px。`maxSpan`（视距上限）在它之后生效，顶住上限时允许裁边。

示例：[按地点自动取景](../site/examples/camera-fit.html)、[按路线取景与 maxSpan](../site/examples/camera-route.html)。

## 总览 {#overview}

- 全线总览单独放宽视距上限：整条长征约 1.3 万 km，默认上限 3400 会顶住，路线显示不全，要放到 16000，并检查是否真的顶到上限。
- 所有地点离底图边缘要 > 400 px，否则底图外的灰色远景会露出来。
- 全图镜头必须满足合规：台湾、海南、南海诸岛完整（见 [合规](compliance.md)）。

## 「地图平淡」怎么办 {#flat}

「平淡」指**画面没变化**，不是地形不够起伏。加地形夸张解决不了（长征 ep04 试过，被否），有效的是：

- 点亮地名（三态切换）
- 出印章、大字数字、速查表
- 跟飞路线头部、拉远到总览
- 叠暗转场进三维窗

## 窄谷与近景

- 陡峡谷近景：地形夸张 1.0 → 0.65，俯角 30–36°。
- 窄谷找不到机位（腊子口）：方位放宽到 180°，俯角抬到 55–65°；日志里出现 relax / WIDEN 的机位必须拍静帧检查。
- 人物（三维窗）最近 ≥ 11.5 m，不给面部近景。

## 录制约束 {#record}

- 录制只用 `jumpTo`，不用 `easeTo` / `flyTo`。后两者按真实时钟插值，截帧一慢画面就变。
- 镜头插值由 Story 按 t 计算，再 `jumpTo`：同一个 t 永远同一个机位。
- 录制前 `precacheViewports` 把所有关键机位走一遍。
- 地图与三维窗之间用深褐叠暗过渡（峰值 0.7–0.96），相邻机位相距 < 25 m 时不压暗；硬切为 0。两边雾色 / 底色要一致，否则切换时整屏跳色。

## 参数速查

| 参数 | 默认 | 来源 |
|---|---|---|
| 安全区 | `[0.06, 0.22, 0.94, 0.78]` | camfit.py |
| 移动时长 `move` | 2.2 s | 长征 ep02 |
| 缓推 `push` | +0.06 ~ +0.09 zoom | 长征 ep02 r11 |
| 俯仰 `tilt` | +3° | camfit Rig |
| 默认俯角 | 40° | camfit.py |
| 总览上限 `maxSpan` | 16000（全线）/ 3400（单集） | 长征 ep12 |
| 三维窗过渡坡道 | 0.9–0.95 s | 长征 ep09 |
