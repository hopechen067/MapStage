# 合规 Compliance

MapStage 的默认底图和默认规则按国内视频平台审核来定。这些规则**默认开启**；要关，必须在 story 里显式声明并自己承担审核风险。

## 地图画面

| 规则 | 默认实现 | 来源 |
|---|---|---|
| 不画省界、国界（十段线例外） | 底图删除所有 `vl-boundary*` 图层；自检发现境界图层即失败。南海十段线不算境界图层，见下一行 | 长征 ep03 抖音「画面」违规 |
| 全图必须画南海十段线 | Story 运行时在 `compliance.full` 时段显示 `ms-ten-dash` 图层；自检要求它可见。要关必须在 story 写 `compliance.tenDash: false` | 《公开地图内容表示规范》，2026-10-23 定 |
| 不加雾化 | style 不写 `fog`；距离雾关闭 | 长征 ep14 v3 未过审 |
| 不加暗角 | 皮肤 / preset 的 `vignetteStrength` 在录制路径按 0 处理 | 长征 ep14 v3 未过审 |
| 全图时台湾、海南、南海诸岛、海岸线完整 | 自检检查这些点是否都在画内 | 长征系列总规则 |
| 不用裁切「躲」掉南海 | 全图镜头的取景不得把南海诸岛排除在外 | 同上 |

## 自检

```js
const report = MapStage.complianceCheck(map, { full: true });
// [{ id: 'no-borders', label: '不画省界 / 国界', ok: true }, …, { id: 'nanhai', ok: false }]
```

`full: true` 时额外要求台湾、海南、南海诸岛的参考点都在当前画面内，并且十段线图层可见（`MapStage.addTenDash(map)` 添加；Story 运行时自动添加）。Story 运行时会在 `compliance.full` 标注的时间段逐帧跑自检，不过就拒绝渲染。

## 封面与片头

- 封面和片头前 3 秒不放陷人、溺水、倒地、尸体的画面（长征 ep11 因陷水举手的封面与第 0 帧被判违规）。
- 前 5 秒不放回顾或空地图；第 0 帧就要有内容（大字数字 + 重击）。

## 文字与人物

- 口播和字卡用「毛主席」；屏幕上「毛泽东」只出现在书名里（长征系列约定）。
- 毛主席不放单人照，合影可以用（注资料照、时间地点）；非当地当时拍的照片标「资料照」。
- 惨烈细节按平台尺度改写：例如「押送途中绞断肠子」改为「壮烈牺牲」，三维里也不画。
- 史实措辞以核查报告为准（如四渡赤水用「未达预期」「示形」）。

## 数据声明

MapStage 的地图是**示意性历史地图**，不作为权威边界依据。演示用的中国轮廓（区域拆出）取自国家地图集标准表达（含藏南、台湾、钓鱼岛及南海诸岛、十段线），是叙事轮廓，不是官方边界。数据来源见仓库根 `DATA-PROVENANCE.md`。

## 边界数据复核（2026-10-23）

对象：`tuner/assets/region-isolate-data.js` 里的 `china` / `xizang` / `haiyu` 及岛群模块（Natural Earth 10m 中国视角 + geojson.cn `100000.json` 补充）。

### 画面规则：符合

- 轮廓含藏南、阿克赛钦、台湾、香港、澳门、海南；东沙、西沙、中沙、黄岩岛、南沙、曾母暗沙、钓鱼岛及附属岛屿均有独立小多边形（`region-isolate-data.test.mjs` 锁定）。
- 拆出只是羊皮纸遮罩 / 地形岛，不加境界线图层，不违反「不画省界、国界」。

### 未解决

3. **审图号。** 《地图管理条例》要求向社会公开的地图送审并标注审图号，展示或登载非出版物地图由展示者 / 登载者送审；「内容简单的地图」可豁免，但条文没有明说视频里的示意性全图算不算。最稳妥的做法是全图镜头直接用自然资源部标准地图（自带审图号，按要求标注），MapStage 只做叙事层。这一条需要按平台和发布方式自行判断，必要时咨询测绘地理信息主管部门。

结论（2026-10-25 更新）：画面规则过关；数据来源已换成公共领域的 Natural Earth，geojson.cn 许可阻塞解除。审图号（第 3 项）仍待用户判断；公开仓库里现有的旧数据和历史需在同步时一并处理。
